Documentação

Declaração de acessibilidade

O Recycling Circle é um projeto acadêmico desenvolvido com acessibilidade como requisito estrutural da interface.

Princípios aplicados

  • Conteúdo estruturado semanticamente para tecnologias assistivas.
  • Navegação completa por teclado.
  • Foco visível nos elementos interativos.
  • Texto alternativo e uso de conteúdo decorativo de forma apropriada.
  • Labels e mensagens de erro associados aos campos de formulário.
  • Uso de lang="pt-BR" para identificação do idioma.
  • Respeito à preferência prefers-reduced-motion.
  • Layout responsivo e compatível com ampliação do conteúdo.

Referência WCAG 2.1

O projeto foi organizado considerando os princípios Perceptível, Operável, Compreensível e Robusto da WCAG 2.1.

Testes Aplicados

  1. Navegar pelo site usando somente Tab, Shift + Tab, Enter, Espaço e Esc.
  2. Verificar a ordem lógica de foco.
  3. Executar a interface com NVDA e um navegador compatível.
  4. Verificar contraste com ferramenta de avaliação.
  5. Executar auditoria automatizada com Lighthouse.
  6. Ampliar o navegador e verificar se conteúdo e funcionalidades continuam disponíveis.
